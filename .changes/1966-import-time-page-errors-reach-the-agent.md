### Fixed

- **`@reticlehq/server` — an app that threw while its modules were evaluated showed the agent a blank page and no cause.** An import-time error fires while the first navigation is still running, before the SDK is injected, so no window listener existed to catch it: `reticle_console` reported an unrelated 404 and a bare count, and the agent had to re-run the app under headless Chrome with `--enable-logging` to learn why the page was empty. The leased page's Playwright handle is now attached before the first navigation, the journal buffers what it hears per lease, and the session receives the exception with message, stack and `file:line` the moment it connects — deduplicated against the SDK's own report of the same throw. Closes [#1966](https://github.com/reticlehq/reticle/issues/1966).
