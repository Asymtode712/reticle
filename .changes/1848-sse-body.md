### Fixed

- **`@reticlehq/browser` — capture streamed SSE replies.** With network body capture on, Reticle now records `text/event-stream` responses without blocking the app or delaying settle. Capture stops at its size bound or after 10 seconds. JSON event data uses structured credential redaction. Credential redaction now handles quoted keys and values in all text bodies, not only SSE. Incomplete bodies carry a truncation flag, so missing text returns `unknown`, not `no`. For a stream that stays open below the size bound, the body appears only at the 10-second deadline. This exceeds the default `act_and_wait` budget, so a body clause can return `unknown` within that call. Use `wait_for` to wait for capture. Closes [#1848](https://github.com/reticlehq/reticle/issues/1848).
